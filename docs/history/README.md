# Histórico de revisões

Esta pasta preserva diagnósticos, auditorias e revisões de entregas anteriores. Os números de testes, caminhos antigos, estado de serviços e pendências descrevem a data de cada relatório e podem ter mudado.

Para a operação atual, use o [índice dos guias](../README.md) e o [guia de migrações](../../backend/db/README.md). Não execute SQL antigo apenas porque aparece em um relatório histórico.
